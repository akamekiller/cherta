# Черта

Приложение для прописей китайских и японских иероглифов: карточки с проверкой написания, тетрадь прописей, словарь, упражнения, теория.

- Сайт (ставится на телефон как приложение): https://akamekiller.github.io/cherta/
- Android: [cherta.apk](https://github.com/akamekiller/cherta/releases/download/android/cherta.apk)
- Windows: [Cherta-Setup.exe](https://github.com/akamekiller/cherta/releases/download/windows/Cherta-Setup.exe)
- Новости и сообщения об ошибках: [Telegram-канал](https://t.me/+h5g131MEvYAwMzIy) или Issues этого репозитория.
