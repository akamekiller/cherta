# Черта

Прописи китайских иероглифов: пишешь пальцем, приложение проверяет каждую черту, вводишь пиньинь, а повторения раскладываются по FSRS.

## Запуск на компьютере

Нужен только Node.js (уже установлен). В PowerShell:

```
cd $HOME\Documents\cherta
npm start
```

В окне появятся две ссылки:
- `http://localhost:5173` — открыть в браузере на этом компьютере;
- `http://192.168.x.x:5173` — открыть на телефоне, если он в той же Wi-Fi сети.

Остановить сервер: `Ctrl+C`. Если Windows спросит про доступ к сети для Node.js, разрешите «Частные сети», иначе телефон не подключится.

Офлайн-режим и установка иконкой на телефон заработают, когда сайт будет выложен по https (GitHub Pages).

## Что в папке

| Папка | Что там |
|---|---|
| `site/` | Готовый сайт. Его запускает `npm start` и его же выкладываем в интернет |
| `src/core/` | Логика без интерфейса: пиньинь, FSRS, авто-оценка, колоды |
| `src/ui/` | Экраны: главная, занятие, слова, настройки |
| `src/store.ts` | Сохранение прогресса в браузере (IndexedDB) |
| `static/` | Шаблон страницы, стили, иконки, service worker |
| `data/` | Колоды в виде таблиц (`hsk1.tsv`) и их список (`decks.json`) |
| `tests/` | Проверки логики |
| `vendor/` | Библиотека hanzi-writer (исходники) и лицензии данных |
| `scripts/` | Сборка, локальный сервер, нарезка данных черт |
| `prototype/` | Первая версия в одном файле, для истории |

## Для разработки

Если менять код самому, один раз установить инструменты сборки:
```
npm install
```
Потом:
- `npm run build` — пересобрать `site/` из `src/` и `static/`;
- `npm test` — проверить логику;
- `npm run typecheck` — проверить типы.

## Своя колода

Создайте файл в `data/` с тремя колонками через Tab: иероглифы, пиньинь с цифрами тонов, значение. Первая строка: `word	pinyin	meaning_ru`. Добавьте колоду в `data/decks.json` и пересоберите.
